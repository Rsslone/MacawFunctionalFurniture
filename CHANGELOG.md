# Changelog
## [1.2.0] - 2026-05-09
### Fixed
- Fixed furniture inventories not rendering tooltips.
### Added
- Added container names to the GUI. Uses MCW's base block name.
- AABB Override which delegates to the master MCW block, block highlights now are consistant while hovering a filler.

## [1.1.0] - 2026-04-29
### Added
- Furniture multiblock fillers are placed in spaces the models exist in, this allows interactions to more closely reflect where you are clicking. Pre-existing blocks will need to be picked up and placed to recieve it.
- Added mod update URL, for the rare cases an update might exist. (Like this one.)
